AI & Reinforcement Learning

The Machine That Learned to Play

“92% win probability, 85% positional accuracy — a self-learning agent built from first principles using TD learning and heuristic search.”

What does it take to teach a machine strategy? For the board game Abalone, I designed an end-to-end AI system using reinforcement learning and principal variation search — trained to play and improve entirely through self-play.

The result: an agent achieving 92% win probability and 85% positional accuracy, with a live GUI letting users calibrate difficulty in real time.

AI & Audio Processing

Voice as a Window to Emotion

“Teaching machines to hear what we feel — a real-time emotion recognition system.”

Human emotion leaks through voice — pitch, rhythm, hesitation. This system captures those signals through MFCC extraction, noise reduction, and temporal feature aggregation, then classifies emotional states using a supervised learning pipeline.

Designed with a multimodal extension in mind: future versions will fuse speech signals with facial expression analysis for richer emotional context.

“Gesture-driven media control — bridging body language and machine understanding.”

Using a standard webcam, this Chrome extension translates hand gestures into browser video control — play, pause, volume, scrubbing — entirely through a real-time computer vision pipeline.

004
ML & Geospatial Data

Predicting the Flood Before It Comes

“Satellite imagery + ML — early warning for flood-prone regions.”

By integrating SAR imagery, rainfall, soil moisture, and terrain elevation into a Random Forest pipeline, this system forecasts flood risk for vulnerable regions 7 days in advance — achieving 82% prediction accuracy.

Data was processed through Google Earth Engine, extracting geospatial features that power time-series risk scores offering actionable early warning.

Every Room, In Real Time

“A Django API wired to Raspberry Pi sensors — live occupancy tracking for campus spaces.”

This full-stack IoT project connects Raspberry Pi Pico W microcontrollers with ToF distance sensors to a Django REST API, providing real-time occupancy data for any monitored space.

Data Engineering & Finance

The Market Never Sleeps

“An end-to-end ETL pipeline that ingests financial and sentiment data, transforms it in Snowflake, and surfaces it in Tableau.”

Orchestrated with Apache Airflow, this pipeline continuously ingests financial market data and sentiment signals from public APIs, landing raw records in Amazon S3 before staged transformation in Snowflake using analytical SQL.

Watching the Market That Never Stops
